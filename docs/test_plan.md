# Frappe CRM 测试计划


## 1. 项目背景

本项目基于开源 CRM 系统 Frappe CRM 搭建测试环境，
针对企业客户管理场景开展 Web 功能测试、接口测试以及自动化测试。

通过测试验证系统核心业务流程的正确性，提高系统稳定性和可靠性。


## 2. 测试目标

1. 验证系统核心业务功能是否符合需求。
2. 验证接口数据传输及返回结果是否正确。
3. 验证数据库数据是否正确保存。
4. 使用自动化测试提高接口回归测试效率。


## 3. 测试环境

| 项目 | 环境 |
| --- | --- |
| 操作系统 | Windows 11 |
| 部署环境 | WSL2 + Docker |
| 被测系统 | Frappe CRM |
| 后端框架 | Frappe Framework |
| 数据库 | MariaDB |
| 接口测试工具 | Postman |
| 自动化框架 | Python requests + pytest |
| 数据库工具 | Navicat |


## 4. 测试范围

本项目主要测试以下模块：

### 4.1 登录模块

测试内容：

- 用户登录
- 用户名密码校验
- 登录失败提示
- 登录状态保持


### 4.2 Lead线索管理

测试内容：

- 新增线索
- 修改线索
- 查询线索
- 删除线索


### 4.3 Contact联系人管理

测试内容：

- 新增联系人
- 修改联系人
- 联系信息校验


### 4.4 Deal商机管理

测试内容：

- 创建商机
- 修改商机状态
- 商机流程验证


## 5. 测试方法

### 5.1 黑盒测试

从用户角度验证系统功能，不关注内部实现。


### 5.2 等价类划分

针对输入数据划分有效和无效类别，减少测试数量，提高测试效率。


### 5.3 边界值分析

针对字段长度、数值范围等边界条件设计测试。


### 5.4 接口测试

使用 Postman 验证：

- 请求参数
- 返回状态码
- 返回数据


### 5.5 自动化测试

使用 Python requests + pytest 编写接口自动化脚本。
